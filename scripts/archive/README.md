# Archived diagnostics

One-off scripts written to answer a single question during development, moved
here by the September 2026 audit. None was referenced in `package.json`; several
duplicate each other with different hard-coded limits.

Moved rather than deleted because some were never committed, so deleting them
would have been unrecoverable. Nothing here is wired into the app — if one turns
out to be useful, move it back and give it an npm script so the next person can
find it.
